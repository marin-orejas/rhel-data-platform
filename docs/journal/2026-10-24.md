## What broke and how I fixed it
- The local repository task cost me the most points. I built it in a directory that belonged to another task, so the path and the `baseurl` did not match. I now take every path from the task text and check it with `ls`.
- dnf installed a package from the normal repositories, not from my local one, because they have it too. `dnf install --repo <id> <package>` (or `--disablerepo='*' --enablerepo=<id>`) picks the repository, and `dnf list installed <package>` shows `@<id>` in the repo column.
- Two values came from an example, not from the task: a `gpgkey=` path to a file that does not exist (it worked only because the key was already imported), and a new PATH entry at the start instead of at the end. `PATH=$PATH:<dir>` adds at the end, `PATH=<dir>:$PATH` at the start, and `su - <user> -c 'echo $PATH'` shows the result.
- Copying a directory to another host took me about ten tries: `scp` needs `-r` for a directory, and its port option is `-P` (capital), not `--port`; `ssh` uses `-p`.
- My rsyslog rules were right, but I never tested them. `logger -p <facility>.<priority> "test"` and a look at the target file prove a rule.
