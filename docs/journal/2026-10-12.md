## What broke and how I fixed it
- `useradd -g` sets the primary group and `-G` the secondary groups. `id <user>` reads it back.
- The sshd settings went to the client directory `/etc/ssh/ssh_config.d/` a second time. In exam 05 I used the right directory and a file name that sorts first, but kept a value that the task wanted changed.
- `grub2-mkconfig` ran before I saved the timeout change, and in exam 05 not at all. It runs after the last save, and `grep 'set timeout=' /boot/grub2/grub.cfg` reads it back.
- A umask in root's `.bashrc` covers only root. For one user it goes in that user's `.bash_profile` or `.bashrc`, for every user in `/etc/profile.d/*.sh`.
- One line in `chrony.conf` without the `server` keyword made chronyd refuse the whole file. I never restarted chronyd during the exam, so the error showed only after the reboot.
- An SSH key with its own name, like `~/.ssh/ed25519`, is never offered by a plain `ssh`, which tries only `~/.ssh/id_*`.
- An autofs master file in `/etc/auto.master.d/` must end in `.autofs`, or autofs ignores it.
- `/etc/nologin` is not a shell. It is a file that blocks every non-root login while it exists. The shell is `/sbin/nologin`.
- "Remove any other repository definitions" means delete them, not set `enabled=0`.
- An NFS line in fstab needs `nfs-utils`. `mount -a` would have shown it.
