## What broke and how I fixed it
- A drop-in that should set the nice value of a service did nothing. It held only `nice=10`, with no `[Service]` header and a lower-case key, and systemd ignores both without a word. The right file has `[Service]` and `Nice=10`, and `systemctl show -p Nice <unit>` shows the value really in effect.
- `lvextend -r -L 512M` on a bigger LV changed nothing: `-L 512M` is an absolute size, and lvextend does not shrink. To grow by a size, it is `-L +512M`.
- A typo in a target directory cost half of an archive task. I now read back every path I typed with `ls`.
