## What broke and how I fixed it
- I missed the second part of a task, an SELinux boolean. I now tick off every part of a task before I move on.
- A sudoers rule named a misspelled user. `visudo -c` checks the syntax only, not whether the user exists; `sudo -l -U <user>` shows what a user may really run.
- In a script, `grep $1 /etc/passwd` matches anywhere in a line, so a short name also matches longer ones. `grep "^$1:" /etc/passwd` or `getent passwd "$1"` finds exactly one user.
- The swap line in fstab had `defaults` without the priority the task asked for. `pri=10` goes in the options, and `swapon --show` shows `PRIO`.
- I swapped two repository IDs and their URLs. `dnf repolist -v` shows which URL each ID uses.
